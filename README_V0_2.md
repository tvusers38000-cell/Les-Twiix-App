# Les Twiix V0.2 — Fondations fonctionnelles

Ce correctif transforme le prototype visuel en première base interactive :
- statut LIVE modifiable ;
- actualités administrables ;
- planning administrable ;
- Top donateurs administrable ;
- défis administrables ;
- sauvegarde locale via SharedPreferences ;
- espace Admin de démonstration accessible depuis Profil.

## Installation dans le dépôt existant
Décompresser ce ZIP à la racine du dépôt `Les-Twiix-App`, puis commit/push.

Le correctif ne remplace pas votre workflow GitHub ni les fichiers d'icône déjà corrigés.

## Important
Cette V0.2 est encore un prototype local : les changements Admin ne sont visibles que sur l'appareil qui les effectue. La prochaine phase consistera à connecter un backend sécurisé afin que les admins modifient le contenu pour tous les utilisateurs.
